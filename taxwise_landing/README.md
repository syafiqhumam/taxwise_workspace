# TaxWise Consulting

Situs statis landing page konsultan pajak di Samarinda.

Konten ada di `data/content.json`. **Jangan** buka `index.html` langsung dari Explorer (`file://`) — konten tidak akan termuat.

## Preview lokal

Dari folder **ini** (`taxwise_landing`):

```powershell
npm run dev
```

Lalu buka **http://localhost:3000**

Jika server dijalankan dari folder induk `taxwise_workspace`, buka **http://localhost:3000/taxwise_landing/** (atau klik redirect di halaman root).
